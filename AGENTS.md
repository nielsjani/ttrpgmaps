## Architecture

Angular 16 app with **hash-based routing** (`useHash: true`). Four independent feature modules:

| Module | Route | Entry point |
|---|---|---|
| Map viewer | `/:mapId`, `/:mapId/:subMapId` | `map-container/` |
| Character Creator | `/character-creator` | `character-creator/` |
| Shop Generator | `/shop-generator` | `shop-generator/` |
| Starfinder | `/starfinder/...` | `starfinder/` |

CharacterCreator, ShopGenerator, and Starfinder are **lazy-loaded** via `loadChildren` in `app-routing.module.ts`.

## Map Viewer Data Flow

Map data is defined as **TypeScript classes** (not JSON, not services) in `src/app/data/`. Each class implements the `MapData` interface (`src/app/types/map-data.ts`):

```typescript
export interface MapData {
  getMapMetaData(): MapMetaData;  // Leaflet bounds, zoom, image path
  getMarkerData(): MarkerData[];   // icon markers (lat/lng + icon file)
  getPoiData(): PoiData[];         // sidebar/popup entries (plain text or HTML)
  getSubMap(markerId: string): MapData | undefined;  // nested maps
}
```

`MapDataService` (`src/app/data/map-data.service.ts`) is a plain class, **not an Angular injectable** — it is instantiated with `new MapDataService()` directly inside `MapContainerComponent`. It holds a hard-coded `Map<string, MapData>` keyed by URL-safe string (e.g. `"sword-coast-leuven"`).

`MapContainerComponent` reads `:mapId`/`:subMapId` from route params and passes `MapMetaData`, `MarkerData[]`, and `PoiData[]` as `@Input()` to `MapComponent` (Leaflet).

**Critical**: switching between top-level maps triggers `window.location.reload()` — Leaflet cannot be re-initialized in the same DOM element. See `MapContainerComponent.hardReloadOnMapChange()`.

## Adding a New Map

1. Create `src/app/data/my-map-data.ts` implementing `MapData`.
2. Register it in `MapDataService.mapDatas`: `["my-map", new MyMapData()]`.
3. Place map image under `src/assets/maps/` and icons under `src/assets/icons/` (rendered at 50×50 px).
4. `MapMetaData` bounds use Leaflet `LatLngBoundsExpression` `[[-y, -x], [y, x]]` — use the browser console click handler (logs lat/lng on click) to calibrate.
5. `PoiData.description` and `MarkerData.popupText` accept raw HTML strings rendered directly in map popups.
6. Sub-maps: set `PoiData.subMapId` and implement `getSubMap()` returning a nested `MapData` instance.

See `src/app/data/phandalin-map-data.ts` for a complete example with HTML descriptions and marker coordinates.

## Starfinder Module

Content is served as **static JSON** from `src/assets/data/starfinder/`:
- `alien-index.json` / `starship-index.json` — list views
- `alien/<slug>.json` / `starship/<slug>.json` — detail views
- `universal-monster-rules.json`

JSON files are generated by Python scrapers in `/scraper/`. HTML in JSON descriptions is rendered via `SafeHtmlPipe` (DomSanitizer bypass) — see `src/app/starfinder/pipes/`.

## Key Conventions

- **SCSS** for all component styles; global styles in `src/styles.scss`.
- Feature modules each have a `*Module` + `*RoutingModule` pair using `RouterModule.forChild()`.
- `MapDataService` is **not injectable** — always instantiate with `new`.
- No state management library; components use `@Input()`/`@Output()` and route params.
- The `subscribe` in `MapContainerComponent.ngOnInit()` is intentionally never unsubscribed (noted in a comment).
